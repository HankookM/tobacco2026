사용 안내

  1. 판매 발생 시 입출고 → 판매 입력에서 바코드 스캔 후 담기/저장.
  2. 박스 입고는 입출고 → 입출고에서 입고로 등록.
  3. POS CSV는 입출고 → CSV 업로드에서 일괄 반영.
  4. 새 담배는 입출고 → 신규 담배 탭에서 등록.
  5. 판매·입출고 내역 확인/취소는 입출고 → 최근 기록.
  6. 재고조회 → 목록에서 갑(노란줄) / 보루(파란줄) 칸이 강조됩니다. 행 끝 ✏️ 버튼으로 단가·안전재고·메모 등을 수정할 수 있어요.
  7. 판매로 갑이 0 이하가 되면 자동으로 보루 1개를 풀어 갑 +10으로 환산합니다.
